# 블롭 컨트롤 (Blob Control)

"Mob Control" 스타일의 웹 브라우저 미니게임입니다. 순수 HTML/CSS/JS로 만들어져 있어 별도 빌드 없이 바로 실행할 수 있습니다.

## 실행 방법

정적 파일 서버로 열면 됩니다. 예:

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.

## 게임 방법

1. **빌드 단계**: 코인으로 트랙의 빈 칸에 게이트를 설치합니다.
   - `배율 게이트 (×N)`: 지나가는 무리 수를 N배로 늘립니다.
   - `증가 게이트 (+N)`: 무리에 N마리를 더합니다.
   - `공격력 게이트 (⚔×N)`: 무리의 공격력을 N배로 늘립니다.
   - `코인 게이트 ($N)`: 통과할 때마다 코인을 획득합니다.
   - 게이트는 눌러서 업그레이드하거나 판매(50% 환급)할 수 있습니다.
   - 빨간 해골 칸은 위험 지대로, 지나가면 무리 수가 절반으로 줄어듭니다. `◀ ▶` 버튼(또는 방향키/A·D)으로 레인을 옮겨 피하세요.
2. **전투 시작**: 몹이 주기적으로 스폰되어 트랙을 따라 내려가며 게이트를 통과합니다.
3. 트랙 끝에 도달한 무리는 보스와 자동으로 전투를 벌입니다. 제한 시간 안에 보스 체력을 0으로 만들면 승리하고 다음 웨이브로 진행합니다.
4. 실패하면 같은 웨이브를 게이트 구성을 조정해 다시 도전할 수 있습니다.

웨이브가 진행될수록 보스 체력이 증가하므로, 코인으로 게이트를 업그레이드하며 더 강력한 조합을 만들어야 합니다.
